# Jose Pauluk — Planos PIG y gestión de gas

Landing estática preparada para publicación gratuita. No requiere servidor, base de datos ni dependencias.

## Estado de lanzamiento

- Sitio en preparación.
- La matrícula categoría 3 todavía figura como **en trámite**.
- Los servicios con firma no deben promocionarse como disponibles hasta contar con matrícula habilitada y vigente.
- Antes de publicar, reemplazar el estado por número de matrícula, categoría, vigencia y distribuidora/registro correspondiente.

## Publicación sugerida

El sitio puede alojarse sin costo en Cloudflare Pages, igual que `josepauluk.pages.dev`. La carpeta completa es el contenido del sitio; `index.html` es la portada.

## Datos a confirmar antes del lanzamiento

1. Número de matrícula y fecha de habilitación.
2. Radio de trabajo y costo de traslado.
3. Precios finales e impuestos/facturación.
4. Si la visita se descuenta al contratar un paquete.
5. URL definitiva para completar etiquetas sociales.
6. Confirmar el valor del trámite ante ECOGAS y qué observaciones o reingresos incluye.

## Actualización rápida de precios

Los valores visibles están en el bloque `#precios` de `index.html`. El texto del encabezado indica el mes de vigencia.
